# 方块（tetris）运营后台配置

> 给运营 / 部署人配置 SSO 与活动用。配套见 `DEPLOY.md`（部署流程）、`迁移与初始化说明.md`（DB）、`联调自测清单.md`（验证）。

## 1. zhao-sso 注册 app_code = `game-tetris`

在 `h.joho.cn` 的 **SSO 应用管理** 新增应用（对齐现有 `game-xxl`）：

- **app_code**：`game-tetris`
- **应用名**：方块游戏（tetris）
- **token 有效期 / 加密方式**等其余项：对齐 `game-xxl`
- 说明：后端 `sso-exchange` 用 SSO 颁发的 `accessToken` **直验 + 游客认领**，本应用**无需**配置密钥对 / secret。

## 2. return_url 白名单（必填，否则回跳被拒）

前端 `SsoAuth` 跳转拼接：

```
${SSO_LOGIN_URL}?app_code=game-tetris&return_url=${encodeURIComponent(当前页面URL)}
```

当前页即 `https://game.yourbao.cn/tetris/`。**必须在 zhao-sso 白名单加入以下两项（含 / 不含尾部斜杠都要加）**：

- `https://game.yourbao.cn/tetris/`
- `https://game.yourbao.cn/tetris`

漏加会导致回跳报 "redirect_uri 不在白名单"，登录失败。

## 3. 前端注入的 SSO 参数（bin/index.html 的 `window.__APP_ENV__`）

```
SSO_LOGIN_URL=https://h.joho.cn/#/pages/sso/login
SSO_APP_CODE=game-tetris
SITE_URL=https://game.yourbao.cn/tetris/
GAME_SERVER_API_URL=https://game.yourbao.cn
```

回跳后 `Main.ts` 的 `consumeUrlParams` 提取 token → `AuthStore.ssoExchange(accessToken)` → `POST /api/client/v1/auth/sso-exchange` 换本站会话。

> 改 `__APP_ENV__` 无需重新构建，热改即可；详见 `DEPLOY.md` 第三节。

## 4. 跨游戏隔离（务必告知运营）

- tetris 账本（`tetris_*`）与消消乐（`xiao_*`）**完全独立**：积分、进度、皮肤互不通用。
- 同一真实用户在 tetris 与 xiao 是 game-server `players` 体系下的不同 player 行，不会串数据。
- 营销 / 积分活动**不可跨游戏通用**，tetris 需独立配置（见第 5 节）。

## 5. 活动 code / 营销 A/B（可选）

若复用消消乐分享裂变能力（`MARKETING_API_BASE=h.joho.cn`）：

- 在 `h.joho.cn` 运营后台新建活动 code（建议 `tetris-share-2026`），渠道 `tetris-wechat`，文案变体（温情版 / 挑战版）权重各 50。
- 前端 `Env.ts` 注入 `MARKETING_API_BASE`、`MARKETING_CAMPAIGN_CODE` 对应值。
- **无此需求可跳过**，不影响核心登录 / 积分 / 进度功能。
