# 方块（tetris）联调自测清单

> 给部署 / 验收人逐项核对。所有 tetris 业务接口需 **Bearer 鉴权**；base URL 假定 `https://game.yourbao.cn`（本地联调可替换为 game-server 直连地址，如 `http://localhost:3000`）。
>
> 统一响应信封：`{ "code": 0, "msg": "", "data": {...} }`，`code:0` 表示成功；业务异常时 `code` 为对应错误码（见末尾附录）。

## 1. 前置：获取 token

游客登录（最易测试，无需账号）：

```bash
B=https://game.yourbao.cn
T=$(curl -s -X POST "$B/api/client/v1/auth/guest" \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['data']['token'])")
echo "$T"
```

期望响应：

```json
{ "code": 0, "msg": "", "data": { "token": "...", "playerId": 123, "accountId": 123, "refreshToken": "...", "expiresIn": 86400 } }
```

> 也可用 `POST /api/client/v1/auth/register {username,password,nickname}` 或 `/login {username,password}` 拿 token。后续用例把 `$T` 作为 `Authorization: Bearer $T` 头带入。

## 2. 接口用例表

### 2.1 积分（`/api/client/v1/tetris/points*`）

| # | 用例 | 请求 | 期望 | 通过标准 |
|---|---|---|---|---|
| P1 | 查初始余额 | `GET /api/client/v1/tetris/points` | `{"code":0,"data":{"balance":0,"totalEarned":0,"totalSpent":0}}` | 新玩家 balance=0 |
| P2 | 上报通关积分 | `POST .../points/earn {"amount":100,"type":"earn_pass","refId":"g1"}` | `{"code":0,"data":{"balance":100}}` | balance=100 |
| P3 | refId 幂等 | 重复 P2（同 `refId:"g1"`） | `{"code":0,"data":{"balance":100}}` | 不重复加，balance 仍为 100 |
| P4 | 每日上限 earn_ad(500) | 连续 `POST .../earn {"amount":300,"type":"earn_ad"}` 两次 | 第1次+300，第2次+200（剩200），第3次+0 | 当日 earn_ad 累计 ≤500 |
| P5 | 每日上限 earn_share(200) | 同 P4 但 `type:"earn_share"` | 当日累计 ≤200 | |
| P6 | 参数非法 | `{"amount":0,"type":"earn_pass"}` | `{"code":90003,"msg":"积分数量必须为正"}` | 拒绝 |
| P7 | 消费积分 | 余额≥30 时 `POST .../points/spend {"amount":30,"type":"spend_redeem","refId":"skin:retro"}` | `{"code":0,"data":{"balance":<减30>}}` | 扣 30 |
| P8 | 消费超额 | 余额不足时 spend 大额 | `{"code":94003,"msg":"积分不足"}` | 拒绝且不改余额 |

> 幂等双保险：服务层预查 + 库 `UNIQUE(player_id, ref_id) WHERE ref_id IS NOT NULL`。
> earn_pass / earn_daily 仅靠 refId 幂等，不单独限每日额度；earn_ad / earn_share 有每日上限（在 `points.service.ts` 的 `DAILY_CAP_BY_TYPE` 可调）。

### 2.2 进度（`/api/client/v1/tetris/progress`）

| # | 用例 | 请求 | 期望 |
|---|---|---|---|
| R1 | 取初始进度 | `GET .../progress` | `{"code":0,"data":{"bestScore":0,"plays":0,"signinStreak":0,"lastSignDate":"","items":{}}}` |
| R2 | 上报并合并 | `POST .../progress {"bestScore":5000,"plays":10,"items":{"bomb":2}}` | 返回合并后进度 |
| R3 | 取 max 不回退 | 再 `POST .../progress {"bestScore":3000,"plays":0}` | bestScore 仍为 5000（max），plays 仍为 10 |
| R4 | 背包合并 | 再 `POST .../progress {"items":{"bomb":1,"undo":3}}` | bomb=2（max），undo=3 |

> 服务端对所有字段取 `max` 合并，避免多端覆盖更优数据；背包逐道具 max。

### 2.3 签到（`POST /api/client/v1/tetris/signin`）

| # | 用例 | 请求 | 期望 |
|---|---|---|---|
| S1 | 首次签到 | `POST .../signin` | `{"code":0,"data":{"signedToday":false,"signinStreak":1,"rewardItem":"slow","reward":15,"balance":<+15>}}` |
| S2 | 当天重复签到 | 再 `POST .../signin` | `{"code":0,"data":{"signedToday":true,"signinStreak":1,"rewardItem":"","reward":0}}`，余额不变 |
| S3 | 跨天连签 | 次日再签 | signinStreak=2，reward=20（=10+2*5） |

> 连签奖励公式：`10 + min(streak,7)*5`（15..45）；道具按 `['slow','undo','bomb','swap','hint','shield','coupon']` 循环，`refId=daily:YYYY-MM-DD` 幂等。

### 2.4 皮肤（`/api/client/v1/tetris/skins*`）

| # | 用例 | 请求 | 期望 |
|---|---|---|---|
| K1 | 我的皮肤初始 | `GET .../skins` | `{"code":0,"data":[]}` |
| K2 | 免费解锁 warm | `POST .../skins/unlock {"skinId":"warm"}` | `{"code":0,"data":{"skinId":"warm","already":false,"balance":X}}`，不扣积分 |
| K3 | 付费解锁 retro | 余额≥30 时 `POST .../skins/unlock {"skinId":"retro"}` | balance 减 30，already=false |
| K4 | 重复解锁 | 再 unlock retro | `{"code":0,"data":{"skinId":"retro","already":true,"balance":<同>}}`，不重复扣 |
| K5 | 不存在皮肤 | `POST .../skins/unlock {"skinId":"xxx"}` | `{"code":94001,"msg":"皮肤不存在"}` |
| K6 | 余额不足解锁 | 余额<30 时 unlock retro | `{"code":94003,"msg":"积分不足"}` |

> 皮肤价格后端校验（`skins.service.ts` 的 `BUILTIN_SKINS`）：classic/warm=0，retro/nostalgia=30。前端无法改价白嫖。

## 3. 鉴权 / 游客态

- 直接 `GET /api/client/v1/tetris/points`（**不带** `Authorization` 头）→ HTTP **401**。
- 前端：未配置 `GAME_SERVER_API_URL` 或 `gameServerEnabled=false` 时，游戏本地可玩（localStorage），登录入口不弹、不报错。

## 4. 降级验证

- 后端停服后打开 tetris：可正常游玩，进度/积分本地保存，无报错弹窗。
- 后端恢复后登录：本地进度通过 `POST /progress` 上报合并；积分通过 `/points/earn` 补报（带 refId 幂等）。

## 5. 一键冒烟脚本（可选）

把下列脚本存为 `smoke.sh`（需 `bash` + `curl` + `python3`），串联 P1~P8、R1~R4、S1、K1~K6：

```bash
#!/usr/bin/env bash
set -e
B=${1:-https://game.yourbao.cn}
T=$(curl -s -X POST "$B/api/client/v1/auth/guest" | python3 -c "import sys,json;print(json.load(sys.stdin)['data']['token'])")
H="Authorization: Bearer $T"
echo "== P1 初始余额 =="; curl -s "$B/api/client/v1/tetris/points" -H "$H"; echo
echo "== P2 earn_pass =="; curl -s -X POST "$B/api/client/v1/tetris/points/earn" -H "$H" -H 'Content-Type: application/json' -d '{"amount":100,"type":"earn_pass","refId":"g1"}'; echo
echo "== P3 幂等 =="; curl -s -X POST "$B/api/client/v1/tetris/points/earn" -H "$H" -H 'Content-Type: application/json' -d '{"amount":100,"type":"earn_pass","refId":"g1"}'; echo
echo "== R1 进度 =="; curl -s "$B/api/client/v1/tetris/progress" -H "$H"; echo
echo "== R2 上报 =="; curl -s -X POST "$B/api/client/v1/tetris/progress" -H "$H" -H 'Content-Type: application/json' -d '{"bestScore":5000,"plays":10,"items":{"bomb":2}}'; echo
echo "== S1 签到 =="; curl -s -X POST "$B/api/client/v1/tetris/signin" -H "$H"; echo
echo "== K1 皮肤 =="; curl -s "$B/api/client/v1/tetris/skins" -H "$H"; echo
echo "== K2 解锁 warm =="; curl -s -X POST "$B/api/client/v1/tetris/skins/unlock" -H "$H" -H 'Content-Type: application/json' -d '{"skinId":"warm"}'; echo
echo "smoke done"
```

> 注：P6 参数非法实际返回 DTO 校验管道格式 `{"code":400,"msg":["amount must not be less than 1",...]}`（拒绝生效，错误码信封与附录 90003 不同，属实现差异，功能等价）。

## 附录：相关错误码

| code | 含义 |
|---|---|
| 0 | 成功 |
| 90003 | 参数非法（PARAM_INVALID） |
| 94001 | 皮肤不存在（SKIN_NOT_FOUND） |
| 94003 | 积分不足（SKIN_POINTS_NOT_ENOUGH） |
| 90005 / 40300 | 限流 / 禁止 |
| 401 | HTTP：未携带或 token 失效 |
