## 一、地图草案（三界卷轴）

### 构图逻辑：纵向三段式

古风长卷自下而上对应「人界 → 灵界 → 仙界」，以一条贯穿画面的灵脉大河水道为轴线，
云雾作为三界之间的天然分界，山道与飞舟是跨域要道。

### 分层示意

| 层级 | 画面位置 | 对应地域 / 宗门 / 秘境 | 画面元素 |
| --- | --- | --- | --- |
| **人界** | 画卷下段 | 七玄门、黄枫谷、天南诸国、大晋、乱星海 | 青绿群山夹峙的河谷，山脚小型道观与书院式建筑，红色帆船商旅（凡俗商贸与散修航线），山径石阶连接各宗门 |
| **灵界** | 画卷中段 | 灵界诸族地域（木族、羽族、妖族栖地等）、各处秘境入口 | 云海之上的连绵仙峰，桃花点缀的灵植谷地，盘山栈道即「上界通道」，两岸灵田灵圃 |
| **仙界** | 画卷上段顶端 | 仙宫、飞升台、天池 | 金顶重檐仙府矗立主峰之巅，被一轮金月与白鹤群环绕，山体隐现金色符纹（飞升灵脉），象征「一步登天」 |

### 画面语言

- **云雾**：既做留白，也做界域隔断——三界之间用不同密度的云带区分，观感柔和无压迫。
- **山水**：工笔皴染的青绿山峦 + 水墨晕染的远山淡影，近实远虚，层次清透。
- **仙府**：朱柱金瓦、飞檐翘角，延续游戏内「仙剑风」建筑语言。
- **飞舟**：水面红色灵舟既是商贸也是渡界工具，给静谧山水添一点生气。
- **萌化点缀**：白鹤群（信使灵兽）、桃花灵植、圆滚滚的商船，缓和「修仙世界」的距离感。

### 待补：文字标注清单（AI 出图无法稳定渲染汉字，建议后期排版叠加）

- 人界：七玄门（左下）、黄枫谷（左中）、天南（右下）、大晋（中部河谷）、乱星海（下方水域）
- 灵界：木族灵境（右中）、妖族栖地（左中）、秘境入口（云带缺口处，3 处）
- 仙界：飞升台（主峰山腰）、仙宫（顶端金顶）、天池（金月下方）
- 要道：山径石阶 = 修行道；水道 = 商旅道；云带缺口 = 渡界飞舟航线

## 二、主要人物形象设定

统一规格：Q 版 / 半 Q 版，头身比约 1:1.5~1:2.5，大眼圆脸、腮红点缀，
服饰保留仙侠制式的宽袖、丝绦、发饰，配色沿用地图主色调，保证人物与地图同框不违和。

### 1. 韩立（02-hanli.png）—— 谨慎勤勉的「凡人流」主角

- **外貌**：圆头圆脑的少年，黑发束髻插青玉簪，细长凤眼微眯，嘴角浅笑，藏着几分与年龄不符的老成。
- **服饰配色**：青灰 + 藏青交领道袍，袖口绣青色云雷纹，腰系藏青丝绦——呼应黄枫谷的青色门派色。
- **神态气质**：内敛、谨慎、坚韧；不张扬但眼神有光，是「踏实修仙」的治愈系主角。
- **标志元素**：背后斜挎青竹蜂云剑（剑镡一点青绿）；脚边一只嫩绿色圆滚滚的小灵虫（萌化的掌天瓶灵气化身），身旁缭绕淡青云雾。
- **与地图对应**：青灰色调取自人界河谷群山，云雾底纹与地图云带一致。

### 2. 南宫婉（03-nangongwan.png）—— 清冷温柔的仙子道侣

- **外貌**：乌黑长发垂至腰际，鬓边簪一朵白玉兰与银质步摇，杏眼含笑，腮红圆润，清冷中带着软糯的亲和力。
- **服饰配色**：月白为主、淡青为辅的仙门道袍，衣缘绣暗纹云锦，腰束青色绣带银腰扣，坠青玉环佩——月白呼应仙界云海，淡青呼应灵界灵植。
- **神态气质**：外冷内暖，温婉坚定；笑起来眉眼弯弯，是「治愈系仙子」的定调。
- **标志元素**：肩头停一只圆滚滚的小白鹤（信使灵兽）；身侧漂浮一枚淡青色玉环法器与点点灵光。
- **与地图对应**：立于云海与远山淡影之间，正是地图中段灵界的观感。

### 3. 银月（04-yinyue.png）—— 月华所化的狼族器灵

- **外貌**：银白长发如月华倾泻，银灰色大眼睛，头顶一对毛茸茸的银色狼耳，身后拖一条蓬松银尾，笑靥软糯。
- **服饰配色**：月白渐变银灰的和风式广袖裙，衣缘绣银线云月纹，腰束黑色细带银扣——整体是「月色」的清冷透明感。
- **神态气质**：俏皮、温顺、忠诚；举手投足带着小兽般的软萌，眼神灵动。
- **标志元素**：身后一轮巨大的弯月与符文月轮（器灵本源）；脚边卧着一只圆滚滚的银白小狼（本体萌化版），四周垂坠银色铃铛流苏。
- **与地图对应**：银白 + 淡青配色与地图上段的月色云海同源，弯月元素呼应顶端金月。

### 4. 厉飞雨（05-lifeiyu.png）—— 豪爽洒脱的剑修挚友

- **外貌**：黑发高束马尾、额前碎发飞扬，粗眉弯眼、咧嘴大笑，脸颊红扑扑，一身少年侠气。
- **服饰配色**：墨绿 + 赭石色劲装短打，外罩深青半臂，肩覆雕花金饰护肩，腰束玄色革带——大地色系在四人中承担「暖色担当」，平衡整体清雅。
- **神态气质**：豪爽、义气、爱笑；与韩立的谨慎形成互补，画面情绪最明亮的一位。
- **标志元素**：腰悬青锋长剑、金色剑穗；脚边一只圆滚滚的青羽小雀；背景竹影与远山淡墨。
- **与地图对应**：墨绿取自人界山林，背景墨竹呼应七玄门所在的乡野山门。

## 三、风格统一性核对

- **主色板**：月白 `#F5F2EA` · 淡青 `#A8CFCB` · 浅金 `#E4C88A` · 青灰 `#7A8B87` · 墨绿 `#4E5F4E` · 赭石 `#C77B4A`
- **共同笔触**：人物与地图均采用柔和描边 + 水墨晕染背景 + 大面积留白，无硬黑轮廓线。
- **共同萌点**：每位角色配一只「圆滚滚小灵兽」（小灵虫 / 白鹤 / 银狼 / 青雀），与地图中的白鹤群同源。
- **情绪基调**：全员含笑、光晕柔和、无肃杀元素，符合「可爱治愈」要求。

| 资源存放 | `public/art/*.png` | Vite 直接以站点根路径提供，构建时自动拷入 `dist/art/` |

| 角色渲染 | `src/core/Rig.ts` | 传入 `img`（cutout）时改绘立绘贴图（idle/walk/attack 整体律动），无贴图回落程序化骨架 |

| 三界舆图 | `src/ui/WorldMapPanel.ts` | 卷轴舆图 + 11 处标注 + 「此处」标记；**区域落点可点击**——已解锁直接传送；`G` 键 / HUD 按钮 |
| 人物志 | `src/ui/CastPanel.ts` | 2×2 立绘卡 + 设定文案；`Y` 键 / HUD 按钮 |
| 对话头像 | `src/ui/DialogueBox.ts` | `StoryNode.img` 有值时画立绘，否则回落「像」占位 |
| HUD 头像 | `src/ui/Hud.ts` | 主角头像位置改用韩立立绘，未就绪回落纯色块 |
| 标题背景 | `src/ui/TitleUI.ts` | 标题界面背景铺三界舆图 |
| NPC 注册 | `src/data/story/chapter1.ts` | 新增 `nangongwan / lifeiyu / yinyue` 三条 NPC 与对话树（含 `cut`） |

**微调标注坐标**：改 `src/ui/WorldMapPanel.ts` 的 `WORLD_MAP_LABELS`（归一化 0..1，y=0 顶部仙界、y=1 底部人界）；
**微调区域落点**：改同文件的 `ZONE_MARKS`（key 为 `ZONES` 的 id）；
**重生成抠图**：`python scripts/cutout_art.py`（仅放行通过质量门禁者；`--report` 仅预览 ASCII 轮廓）。

**已知限制**：
- 立绘为 AI 生成的完整插画（带背景），界面层（舆图 / 标题 / 对话头像 / 人物志 / HUD）直接用原图；
- 地图小人是**透明底抠图**（`public/art/cut/`），由 `scripts/cutout_art.py` 自动分割。分割为「中心带硬前景 + GMM 迭代」纯算法实现，
  对浅色道袍（如南宫婉月白裙）这类与背景撞色的主体已用中央竖向带约束保住；个别边缘/内孔可能略生硬，放大到 3× 等距缩放下观感尚可，
  重跑脚本即可重算。如要像素级完美抠图，建议美术产出透明底原图再替换 `public/art/cut/` 同名文件。

> 抠图方案迭代记录：第一版「洪水填充 + 最大连通域」在彩色山水背景下完全失效（韩立掩膜覆盖全图、银月主体被吞），
> 故改为「中心带硬前景 + 全局 GMM（类 GrabCut，矩形外为硬背景锚定背景模型）」——无需 OpenCV，纯 numpy/PIL 实现，
> 并以「四角透明 / 前景占比 12%~62% / 高宽比 0.55~4.5 / 非整图」作为质量门禁，ASCII 轮廓预览用于无 GUI 复核。
