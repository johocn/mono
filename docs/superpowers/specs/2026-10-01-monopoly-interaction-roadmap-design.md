# 大富翁（monopoly）互动玩法升级 · 总纲与排期设计

- 日期：2026-10-01
- 范围：`d:\zhao\monopoly`（PixiJS 8 + TypeScript，等距棋盘，390×844 舞台）
- 状态：总纲已确认（采纳排期方案 A）；**§8 决策清单 D1–D37 已全部拍板（全按推荐执行）**，本文档为 M18–M22 的上位约束，各里程碑另出详细设计

## 1. 缘起（客户反馈原文要点）

客户反映该游戏**缺少原版《大富翁》的沉浸感与「互坑」快感**，具体诉求：

1. 落子到格的沉浸感不足
2. 想用**路障**挡自己或拦截别人、**拆别人家**——这类对抗快感缺失
3. 希望**开局只显示棋盘**，买地后建筑一点点生长，直到**五星级**
4. **建筑物颜色与业主颜色一致**，一眼看出棋盘建筑归属谁
5. 玩得不好要**破产拍卖土地，价高者得**
6. **股票交易缺功能**：现在**没有**「指定买哪支 / 卖哪支 / 买多少」的入口（客户原话「股票不能指定买那只，也不能选择性卖出」是**抱怨缺失**）；另需新增**涨跌卡 / 红利卡**及其使用入口
7. **路障、炸弹没有释放对象**：结算层支持目标，但 UI 自动挑目标，玩家没有「选目标」这一步
8. **银行只是个「路过领利息」的格子**：客户要求补上**存款 / 贷款 / 抵押贷款**三条产品线，并给出两条违约规则——**贷款不还 → 多交房租惩罚**；**抵押贷款超期不还 → 拍卖抵押房产**
9. **M21 新玩法要求现在就出方案**（不再是「候选池待选」）
10. **不买地也要有收益来源**：第 **8 轮后**股票市场开放**杠杆交易**；**银行 / 股票所等公共设施可以入股分红**（不是买地）；**收益每轮发布一次**；**收益多少由新闻利好 / 利空决定**

总目标：对齐《大富翁》能力，确保互动玩法**超越**过去，学习先进棋牌游戏的设计，开发新玩法——不是简单加几个按钮。

### 2.1 不可破坏的既有约束

- **17 个商家格一个不动**（业主书面授权清单是产品价值所在，见 `docs/manual-mono.md` M16 节）。
- **确定性**：一律 `makeRng(seed)` 分流，禁止 `Math.random`（回放与 e2e 可复现）。
- **四级可回退体系**（L1 元素覆盖 → L2 皮肤包 → L3 默认皮肤 → L4 内建 `fb`），裸值只允许出现在 L4 内建兜底；`tools/check-hardcoded.mjs` 与 eslint-plugin-mono 为闸门。
- **公有领域合规**：西游 / 三国形象与原著原文可用，影视与网络二创台词一律不用，美术不照搬商业游戏 / 影视剧造型。
- 每次功能交付 = **实现 + 单测/闸门 + 手机视口截图（390×844 @dpr2）+ 手册条目**，收尾一次完成（提交 → 推送 → 部署）。

## 3. 子项目分解与依赖

依赖为**链式**：`M18 → M19 → M20 → M21`。

理由：拍卖他人的地、拆他人的楼，若棋盘上看不出「这是谁的地、几星」，玩家感知不到得失，互坑与竞拍都失去戏剧性。故视觉归属必须先立。

| 里程碑 | 子项目 | 覆盖诉求 | 依赖 | 风险 |
|---|---|---|---|---|
| **M18** | 棋盘生长与归属可视化 | ③ 空盘起步逐级生长、④ 楼体随业主配色 | 无（视觉底座） | 高：推翻「未售地块与 v5 样张逐像素一致」基线 |
| **M19** | 对抗玩法与落子沉浸 | ② 路障 / 炸弹 / 拆屋 + 选目标、① 落格特写 | M18 | 中：动 core 结算 + UI 新交互态 + AI 决策 |
| **M20** | 经济闭环 4 轨道：① 拍卖与自由出售 ② 银行信贷 ③ 股票（含杠杆）与卡片 ④ 公共设施入股与新闻 | ⑤ 价高者得、⑥ 买卖标的与数量、⑦ 涨跌卡 + 红利卡、⑧ 存款 / 贷款 / 抵押 / 违约拍卖、⑩ 设施入股 + 每轮新闻 + 第 8 轮后杠杆 | M18 | 高：已从 1 个子项目膨胀为 4 条轨道，**须拆为 M20.1–M20.4 分别交付**（见 D24） |

## 4. 各子项目设计要点

### 4.1 M18 · 棋盘生长与归属可视化

- **开局空盘**：关掉演示层级通路，改走「真实地产层级」——未售 = 无楼。
- **逐级生长**：买下 → L1，升级 → L2/L3/L4/L5；**五星楼**须有肉眼可辨的体量跃迁（复用 M16 已注册的 `building.s*.l{1..5}` 与 `levelOf` 注入）。
- **归属配色**：楼体（墙体 + 屋面）走**业主色系**；并做「同业主相邻地块街廓连片同色」，使归属一眼成势力图，而非依赖楼顶名牌。
- **过渡表现**：动土 → 起楼，避免 0 直接蹦到 L5 的突兀。
- **开局保留公共设施楼（已定，只保留公共设施、商家格全空）**：现状恰相反——`TILE_LEVEL` 的 18 栋演示楼**几乎全是商家格**，而公共设施格（福利 7/27、银行 9、监狱 12、股票所 19、乐透 21、税务 23、医院 25）**全是空地砖、无楼**。推荐保留 4 栋：

  | 格 | 设施 | 推荐层级 | 理由 |
  |---|---|---|---|
  | 0 | 鹿乡特色小镇（起点） | L3 | 每回合必经，空着最掉档次 |
  | 9 | 鹿乡银行 | L2 | 高频交互 |
  | 19 | 股票交易所 | L2 | 盘面常开，需「看得见在哪」 |
  | 25 | 医院 | L2 | 停 1 回合的负反馈需要实体 |

  技术含义：公共设施格**没有可用楼型**（现有 preset 仅 `stall/shop/market3/onsenHouse/gate/barn`），M18 需新增「银行 / 医院 / 交易所」式楼型或复现有楼型 + 新招牌。

- **L1→L5 换代（现状诊断 + 推荐）**：现状 `levels >= 3` 直接切 `market3` 楼型（`src/render/providers/proc-building.ts:308-310`），L3/L4/L5 只是**行数 +1** ⇒ **L5 与 L3 几乎无差别**，这是「没有升级快感」的根因。推荐**五段式换代（每级新增构件，而非单纯长高）**：

  | 级 | 形态 | 新增构件 |
  |---|---|---|
  | L1 | 单层小摊 | 棚顶 + 幡旗（无灯、无窗格） |
  | L2 | 双层小铺 | 二层 + 雨棚 + 招牌 |
  | L3 | 三层商铺 | 三层 + 转角橱窗 + 招牌塔（现有 `prop.signTower`） |
  | L4 | 四层商厦 | 四层 + 退台（现有 `setbackBox`）+ 屋顶设备箱 + 灯笼 |
  | L5 | 地标五星 | 五层 + 塔楼尖顶 + 霓虹描边 + 业主色光晕 + 地砖发光环 |

- **待拍板（M18 设计阶段）**：业主色染**全楼体**还是只染**屋面 + 门面 + 描边**（避免整盘色块过艳、与皮肤配色体系打架）？见决策清单 D3。

### 4.2 M19 · 对抗玩法与落子沉浸

- **选目标交互**：选中道具 → 棋盘进入选目标态（可作用地块高亮呼吸）→ 点格确认 / 取消，并给**预演**（说明将发生什么、谁会受影响）。
- **拆屋的破坏力与表现**：`bombDown` 现状是「拆 1 级 + L1 炸回无主」，本期要补的是**一次夷平高级楼的销毁力**（口径待定）与**破坏的表现**（楼体崩塌 / 拆除动画，依赖 M18 让层级先可见）。破坏边界：**只作用于地产楼体，不动商家格地砖与店招**（业主授权内容）。
- **路障规则**：明确「挡自己」与「拦对手」两种用法均成立，及被撞破后的后续效果。
- **落子沉浸**：落格镜头推近 + 地块高亮脉冲 + 停顿节奏 + 分量感音效。
- **AI 同源**：AI 必须走同一套目标决策，否则道具有效性只在人类之间成立。

### 4.3 M20 · 经济闭环（拍卖 · 自由出售 · 股票交易 · 股票卡片）

**破产拍卖（口径已定：所有权转移，不从零复建）**

- 不再走 `releaseEstate` 归无主，改为**所有权转移**：成交者**直接继承该地块的所有权 + 收租权**，楼层保持原样（买到即接手现成楼）。
- 起拍价 = `sellAt()` 变卖价；可流拍，流拍处置见决策清单 D11。
- 拍卖所得**优先清偿欠款**，余额分配口径见 D13。

**自由出售房产（新增玩法）**

- 玩家可**任意回合主动变卖自有房产**以筹集资金（现状只有破产时被动自动贱卖，是「无声的剥夺感」来源之一）。
- 价格与折价口径见 D12；出售后地块回归「可购买」状态还是继续挂卖，见 D12。

**股票交易（补功能，非砍功能）**

- 现状：`buyShares/sellShares` 核心具备指定能力，但 UI 只暴露第一支且手数恒 1（见 §2 第 ⑥ 行）。
- 目标：**逐行选中标的**（点某行 = 选中该股）→ **可选数量**（口径见 D5）→ 买入 / 卖出；**支持只卖其中一支**。
- 语义修正说明：客户原话「股票不能指定买哪支，也不能选择性卖出」是**抱怨缺功能**，不是要求限制。

**股票类卡片（新增数据 + 入口）**

| 卡 | 类型 | 建议效果 | 入口 |
|---|---|---|---|
| 涨跌卡 | 道具卡（`target: stock`） | 指定一支股票，令其下回合**必涨 / 必跌** | 手牌槽 → 浮层内选股票 |
| 红利卡 | 道具卡（`target: none`） | 按持仓领分红；无持仓折现固定金额 | 手牌槽 → 点击即用 |

- 连带：`ITEM_CARDS` 由 5 种增至 7 种，手牌槽是否由 5 扩至 7 见 D9。
- 须与既有 `c-stockTip`「内幕消息」区分：内幕消息是**随机**一支，涨跌卡是**指定**一支。

**银行信贷（新增子系统：存款 · 贷款 · 抵押贷款）**

三条产品线（数值为推荐值，见 D17–D22）：

| 产品 | 办理入口 | 额度 | 利率 | 期限 | 违约后果 |
|---|---|---|---|---|---|
| 存款 | 任意自己回合（HUD「银行」常开） | 现金内不限 | +3%/轮 复利 | 随时支取 | 无（欠款清算时被优先动用，**不免死**） |
| 信用贷款 | 须站在 9 号银行格 | `min(￥2000, 净资产 × 30%)` | 6%/轮 | 8 轮 | 逾期 → 付租加收罚息；满 3 轮转强制执行 |
| 抵押贷款 | 须站在 9 号银行格，需选中自有地块 | 抵押地块 `sellAt()` × 80% | 4%/轮 | 6 轮 | 超期 → 抵押地块**进入拍卖** |

**违约规则（客户已定的两条）**

- **贷款不还 → 多交房租惩罚**：逾期后该玩家**每次付租额外支付 50% 罚息**，罚息**不给地主、直接冲抵欠款本金**（逾期越久还债越快，但过程痛苦）。逾期满 3 轮仍未清偿 → 转「强制执行」：拍卖其 1 块地产（复用同一套拍卖引擎）。
- **抵押贷款超期不还 → 拍卖抵押房产**：抵押地块**直接进入拍卖**，起拍价 = `sellAt()` × 80%（即借款额），成交款**先还债、余额归借款人**，不足部分继续追偿。

**抵押期间的地块状态**：**不能出售、不能升级**（`sellAt` / `upgrade` 双重拦截），**但仍可收租**——「抵押物还是你的」，只是被锁住。

**利息结算时点**：每轮末 `endTurn` 统一计息（存款复利进 `deposit`、债务复利进 `principal`）。纯算术、不新增随机源，与确定性回放同源。

**清算顺序改造（`settleDebt`）**：现金 → **存款（自动取出）** → 变卖地产（**跳过抵押中的地块**）→ 折股 → 破产。破产时债务清零（银行承担损失）；抵押物若仍未赎回 → 一并进入拍卖。

**银行格站位加成**：把现有「现金 10% 计息、封顶 ￥300」改写为办理业务的即时好处——落在银行格：① 本回合申请的贷款**首轮免息**；② 领「存款红包」= 当前存款 × 5%（一次性）。让「走到银行」仍有正反馈，同时把利息收益交给存款产品。

**连带架构**：`AuctionTrigger = 'bankrupt' | 'mortgage-overdue'`——破产拍卖与抵押逾期拍卖**共用一套引擎**，只换触发源与「成交前如何处理债务」。

**UI**：新增银行浮层（三栏：存款 / 贷款 / 抵押）与 HUD 债务条（存款 · 债务 · 抵押标记 · 逾期倒计时）。

**AI**：新增 `pickBank(state, P)`——现金低于保留线且有可抵押地块 → 抵押借款；现金充裕且无债务 → 存款；临近期限 → 优先还款。

**连带价值**：让「竞标」成为常规博弈入口，为 M21 的动态要约收购铺路。

**公共设施入股（新增：不买地也有收益来源）**

- **可入股设施 5 处**（**负向格不入股**）：鹿乡银行(9) / 股票交易所(19) / 医院(25) / 乐透彩(21) / 福利中心(7、27)。监狱(12)、税务局(23)、起点(0) **不入股**——它们是负反馈或必经格，分红会破坏语义。
- 每处设施有**固定总股本 20 股**与**固定认购价**（银行 ￥200 / 交易所 ￥180 / 医院 ￥150 / 乐透 ￥120 / 福利 ￥100），玩家认购、**先到先得**，售罄即止。
- **收益率对齐既有经济**：基础分红率统一 **5%/轮**（= 认购价 × 5% × 持股数），**20 轮回本**——高于存款 3%、低于地产的高频收益，与 `ROUND_LIMIT = 60` 匹配（若沿用「100 股 × ￥300」量级，单人一股分红仅 ￥3/轮、回本 66 轮，等于废牌）。
- **每轮末发布一次分红**：`分红 = (基础分红 + 该设施本轮收到的现金流) × 新闻系数 × 持股比例`。
- **关键设计——大股东吃该格的现金流**：设施格的既有「经过效果」不再全部归银行，而是**按股东持股比例分配**：
  - 银行格：别人的**贷款利息**按持股比例分给股东（与上文信贷系统自洽）
  - 股票所：别人的**交易手续费**分成
  - 乐透彩：**入场费**分成
  - 医院：别人住院的**罚金**分成
  - 福利中心：**奖池抽取**分成

  → 「不买地也能收租」，收益与你对设施的掌控度挂钩，形成第二条资产赛道。

**新闻系统（新增：分红与股价的共同驱动）**

- **每轮发布 1 条新闻**（轮首发布、轮末结算），字段：`sentiment: 利好/利空`、`scope: 设施/板块/个股`、`target`、`magnitude`。
- 影响三处：① **公共设施分红系数**（利好 ×1.5 / 利空 ×0.5）；② **股价**（利好标的/板块下轮必涨、利空必跌，与涨跌卡 / 内幕消息同源）；③ **板块租金**（利好板块 ×1.25，可裁剪）。
- 新闻从**固定新闻表**按 `makeRng(seed)` 抽取 → 可回放，不破坏确定性。
- **与 M21「街区事件」的关系**：**两者合并为同一系统**（新闻即事件），M21 只保留「按商圈生效 3 轮」的持续性规则，避免两套并行。

**股票杠杆交易（第 8 轮后解锁）**

- **解锁**：`round >= 8` 时股票浮层出现「杠杆」开关（承接客户「8 轮后」的口径）。
- **机制**：向银行借**保证金贷款**买入，杠杆 **2× / 3×**——自有保证金 X + 借入 (杠杆−1)×X，持仓 杠杆×X；利率沿用信用贷款 6%/轮。
- **爆仓**：持仓市值跌破借款额的 **120%** → **强制平仓**，自动卖出持仓还债；本金归零，**剩余债务转入信用贷款**（继续走 D20 / D21 违约链）。
- **与新闻联动**：利好 → 杠杆收益放大；利空 → 爆仓风险陡增——这正是「学先进棋牌玩法」要的戏剧性。
- **UI**：股票浮层加「杠杆」档位、保证金进度条与**爆仓警告线**。

### 4.4 M21 · 全新玩法方案（已定稿，不再是候选池）

按用户「现在就出方案」的要求，把原候选池收敛为 **3 主 + 2 辅**，延后 3 项并写明理由。

**主线（必做）**

1. **商圈连锁（Chain）**：同一商圈 `tier`（核心 / 文旅 / 农业…）内持有 **≥3 块**即成立连锁——连锁内租金 **+25%**、升级费 **-20%**；成立瞬间在连锁地块之间绘制**业主色连线**。
   *效果*：把「单调涨价」变成「抢地盘布局」的正反馈，逼玩家为连片而竞价。
2. **动态要约收购（Takeover）**：对某商圈持股 **≥2/3** 时，可对剩余地块发起**要约收购**——出价 **120%** 变卖价，对方可拒绝但需付 **5% 违约金**；现金充足可升级为「**强制收购 ×200%**」，对方获得**一次反收购机会**。
   *效果*：拍卖由「破产才发生的罕见事件」变成常态化心理战（承接 M20 的竞标资产）。
3. **街区事件（District Events）· 与新闻系统合并**：**不再独立成系统**——由 M20 的**每轮新闻**驱动，事件只是新闻的「持续性版本」：每 **6 轮**把当期新闻升级为**按商圈生效 3 轮**的板块事件（如「温泉季」文旅类租金 ×2 / 「鹿茸丰收」农业类升级费 ×0.5 / 「疫情管制」医院住院 2 回合且医疗类租金 ×1.5）。
   *效果*：接双阳 IP 与多城市体系，给盘面制造节奏起伏（并让 M20 的抵押贷款与杠杆出现「事件驱动的机会与爆仓」）。

**辅线（与银行系统联动，本期做）**

4. **信贷周期（Credit Cycle）**：每 **8 轮**央行调息一次，存款 / 贷款基准利率 **±1.5%**。降息 → 杠杆泡沫（争相借钱买地）；加息 → 断供潮（抵押拍卖频发）。
   *效果*：把银行从「工具」升级为「宏观层」，让 M20 的信贷状态自动产生戏剧性，而不是玩家手动算账。
5. **破产重组（Restructure）**：破产者**不立即出局**，进入 1 轮「重组期」——可向其他玩家发起**众筹募资**（让出未来 N 轮租金分成），募足即复活。
   *效果*：给落后玩家 comeback 通道，避免早期滚雪球把对局提前打死。

**延后（本期不做，写明理由）**

- **信息战**：与「涨跌卡 / 内幕消息」的信息价值重叠，边际收益低。
- **道具连锁（路障碎片）**：爽感增量小、状态机复杂度高（见 D15）。
- **设施化改造**：需要第二套地砖语义，与 M18 新立的楼型体系冲突，留待下一期。

### 4.5 M22 · 现代棋牌玩法层（参考国内当下热门棋牌）

从国内当下热门棋牌与休闲棋牌产品（斗地主、麻将、小丑牌 Balatro 式倍率、羊了个羊式每日挑战）提炼出四类**低风险、可复用既有通路**的玩法，落到本作「单机 4 人 AI 局 + 确定性回放」的实际形态上：

1. **超级加倍（斗地主式倍率）**：自己回合**掷骰前**可宣布「加倍」——本回合**自己收租 ×2、自己付租 ×2**；每人每局限 **2 次**。
   *效果*：把「稳一手」与「搏一把」的选择交回玩家——穷时不敢加、势均力敌方敢加，制造斗地主式的心理博弈。
   *复用*：既有 `doubleRent` 系数通路，**不新增子系统**。
2. **道具 Combo 倍率（小丑牌 / 自走棋式）**：**同一回合连用两张指定道具**触发组合效果；现有 7 种道具理论 21 组，**首批只做 6 组**高价值组合（见 D34）。
   *效果*：让「囤道具」与「择机出手」有价值，而不是抽到就用。
   *复用*：既有 `useCard` 结算 + 手牌槽；Combo 表为**固定纯函数判定**，不新增随机源。
3. **限时决策倒计时**：所有「选目标 / 选股票 / 选地块」浮层加 **5 秒**倒计时，超时自动走**默认项**（最便宜目标 / 跳过）。
   *效果*：借鉴棋牌「读秒」的紧张感，也给人类与 AI 一致的节奏约束。
   *复用*：纯 UI 计时器；**AI 仍为纯函数决策、不读计时器**，确定性回放不受影响。
4. **每日挑战 + 分享榜（羊了个羊式裂变）**：**固定 seed 的「今日局」**（同一日期全场同一牌序 / 同一新闻流），跑完出**成绩榜**（净资产 / 回合数 / 排名）并生成**微信分享卡片**。
   *效果*：单机游戏唯一的社交钩子——「同一天同一个牌局，比谁打得好」。
   *复用*：既有 `makeRng(seed)` 确定性 + 既有 satori / og-image 与 JS-SDK 微信分享能力（跨项目可复用）。

**不做及理由**

- **身份 / 阵营隐藏角色**（狼人杀式）：与本作 4 人固定角色 + 技能体系冲突，改造成本远超收益。
- **UGC 地图 / 关卡编辑器**：单机无分享生态，等于做给自己看。
- **拼团 / 裂变邀请**：无社交关系链背书，且与 §7「不引入联机」的边界冲突。

## 5. 排期方案

依赖链由 `M18 → M19 → M20 → M21` 延伸为 **`… → M21 → M22`**：M22 是挂在 M19（道具）与 M21（新玩法）之上的低风险扩展层，不影响 M18–M21 关键路径，可最后补齐。

| 方案 | 顺序 | 结论 |
|---|---|---|
| **A（已采纳）** | M18 视觉 → M19 对抗 → M20 经济 → M21 新玩法 | 每步建立在「看得见」之上，互坑与竞拍的爽感才成立；M18 同时解决最直观抱怨 |
| B | M19 对抗 → M18 → M20 → M21 | 互坑最快见效，但拆屋时看不出归属，反馈弱、返工概率高 |
| C | M20 经济 → M18 → M19 → M21 | 经济最完整，但拍卖缺归属可视化的戏剧性，且股票砍功能会先破坏现有 UI |
