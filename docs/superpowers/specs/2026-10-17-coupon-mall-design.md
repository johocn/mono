# 券商城独立页设计

- 日期：2026-10-17
- 状态：已评审（mockup 确认：版式 A + 详情弹层）
- 涉及仓库：nshop（新建页）、vshop（改造 + 入口）、web-admin（后台详情编辑入口）、vendure（零改动，仅核实）
- 关联：券中心渠道隔离修复（vendure commit 0b4dceca3）已上线

## 1. 背景与目标

优惠券售卖（现金购券 / 积分换券）目前藏在 `/coupon` 六 Tab 页内，无独立营销入口，券卡信息密度不足以支撑付费决策。本设计提供**独立的券商城页**，专门承载优惠券售卖与积分兑换，并补齐**券详情**能力。

目标：

- 独立券商城入口（两端、三处入口位），转化导向的商城版式
- 付费券有详情可看：介绍、适用范围、使用信息、购买须知
- 详情为可选增强：有详情展示入口，无详情回退公共信息

## 2. 决策记录

| 决策点 | 结论 |
|---|---|
| 目标端 | nshop + vshop 两端都要 |
| 与现有 `/coupon` 关系 | 并存双入口，`/coupon` 六 Tab 原样不动 |
| 站内入口 | 首页宫格图标 + 我的页/账户菜单 + 券页推广条，两端同步 |
| 页面版式 | 版式 A「楼层导购」：吸顶锚点 + 单券/券包/积分三楼层平铺 |
| 实现方案 | 方案 A：积木复用 + 新页壳，楼层配置内建默认（预留配置位） |
| 券详情 | 详情底部弹层（bottom-sheet），非独立页；介绍取 `description`，购买须知平台统一文案 |
| 详情可见性 | **可选增强**：`description` 非空才显示「详情」入口；无详情券只展示卡片公共信息 |
| 后端 | 零新字段（`description` LocalizedText 已存在且 shop-api 已暴露） |

## 3. 信息架构

```
首页宫格 ─┐
我的页   ─┼─► /coupon-mall（nshop 新页）        pkg-promotion/pages/coupon-mall（vshop 改造）
券页推广条 ┘        │
                    ├─ 热销单券楼层（现金购券，SALE 渠道）
                    ├─ 超值券包楼层（券包，bundle）
                    └─ 积分兑换楼层（POINTS 渠道）
                            │
                            └─ 券详情弹层（可选增强）
```

- `/coupon`（nshop）与 vshop 券包页保持原状，双入口互为导流。
- 路由：nshop `pages/coupon-mall/index.vue` → `/coupon-mall`，SSR 直出，经 `useTenantLocalePath` 带租户前缀（如 `/t2/coupon-mall`）。
- vshop 改造范围：`pkg-promotion/pages/coupon-mall.vue` 五 Tab 结构保留，仅「购券」「积分」两个 Tab 的列表版式对齐版式 A 的卡片设计（uni-app 端自行实现等价卡片组件，与 nshop 不共享代码）；外加 §9 三处入口与详情弹层。

## 4. 页面版式（版式 A·楼层导购）

自上而下：

1. **页头**：返回 + 「券商城」标题 + 积分余额胶囊（已登录时）
2. **吸顶锚点**：热销单券 / 超值券包 / 积分兑换，点击滚动至对应楼层，滚动时高亮当前楼层
3. **热销单券楼层**：`MallCouponCard` 列表，卡片含面额、门槛、名称、场景标签（线上/到店）、已抢进度条、售价、抢购按钮、详情入口（条件显示）
4. **超值券包楼层**：`MallBundleCard` 大卡，含券明细标签（¥50×1 等）、立省金额、合计张数、购买按钮
5. **积分兑换楼层**：`MallPointsCard` 行卡，含面额、积分价、兑换按钮
6. **底部说明条**：平台统一规则摘要

楼层为空时整层隐藏（无 SALE 券则不渲染该楼层与锚点）。

## 5. 组件设计（nshop）

复用：`useCoupon` 取数逻辑（`couponSaleCatalogue`/`pointsMallTemplates`）、`PaySheet`（微信 JSAPI/余额）、`couponYuan` 等工具、`localizeText()`。

新增（`components/coupon-mall/`，纯展示组件，`/coupon` 页不改动）：

| 组件 | 职责 |
|---|---|
| `MallHero` | 页头 + 吸顶锚点（楼层显隐内建默认，常量预留配置位） |
| `MallCouponCard` | 单券抢购卡：面额/门槛/进度条/售罄置灰/价格/抢购/详情入口 |
| `MallBundleCard` | 券包卡：明细标签/立省/合计/购买 |
| `MallPointsCard` | 积分兑换行卡：面额/积分价/兑换 |
| `MallCouponDetailSheet` | 券详情弹层（见 §6） |

进度与售罄：`percent = totalCount > 0 ? claimedCount/totalCount*100 : null`；售罄 = 进度 100% 或 `claimable === false`，按钮置灰文案「已抢罄」。`totalCount === 0`（不限量）不显示进度条。

## 6. 券详情弹层（可选增强）

**显示规则（用户拍板）**：`hasDetail = localizeText(tpl.description) 非空`

- `hasDetail = true`：券卡显示「详情」入口（整卡可点），弹层完整渲染
- `hasDetail = false`：券卡不显示入口，仅展示公共信息（面额/门槛/名称/场景标签/进度/价格），**不弹层**

弹层内容分区（自上而下）：

1. 券头：大面额 + 门槛 + 券名 + 场景标签 + 已抢进度/剩余张数 + 售价
2. **券介绍**（仅 hasDetail）：`description` 按 `\n` 分段渲染多段落，`localizeText()` 回退链（当前 locale → defaultLocale → 首个值）
3. 适用范围：结构化 chips——`scope=ALL` 显示「全部商品」；指定品类/商品只显示「指定范围可用」（不解析品类名，避免额外查询）
4. 使用信息：有效期（`validDays` 或 `startsAt/endsAt`）、每人限购 `perUserLimit`、叠加规则与抵扣方式（模板无此字段，用平台统一固定文案：可与会员折扣叠加、每单限用一张、下单自动抵扣）
5. 购买须知：**平台统一固定文案**（i18n 字典：券类虚拟商品售出后不支持退款等），不逐券维护
6. 底部 CTA：售价 + 「立即抢购」（券包弹层额外含券明细清单区块）

不做富文本渲染（纯文本分段，YAGNI）。

- 券列表页对有详情的券显示「有详情」标记，运营可识别覆盖情况
- 实施时核实现有表单是否已含 `description` 输入；已有则只做布局归组，缺失则补字段

## 8. 数据流与接口

后端零改动。页面加载并行拉取：

```
couponSaleCatalogue(scene)  →  单券楼层 + 券包楼层
pointsMallTemplates         →  积分兑换楼层
```

- nshop 券查询 GraphQL 片段需**补拉 `description` 字段**（vshop 查询已在拉，无需改）
- 抢购/购买：`createCouponSaleOrder` → `PaySheet` 支付 → 我的券
- 积分兑换：现有积分下单链路
- 登录态：页面可匿名浏览；点抢购/兑换时未登录则引导登录（复用现有登录引导）

## 10. i18n 与多城市

- nshop：zh-CN / en-US 同步补全部新词条（页面标题、楼层名、按钮、弹层分区、购买须知等）
- vshop：zh-CN / zh-TW / en / ko / ja **全量**补词条
- 介绍内容本身走 `description` 多语言（后台逐语言维护），与界面 i18n 分离
- 多城市：券商城不涉及配送/仓储判断，仅展示层；静态资源 URL 用动态 origin

## 11. 边界与错误处理

- 未登录：可浏览全部楼层，操作时引导登录
- 售罄：按钮置灰、文案「已抢罄」、进度条满格灰色
- 空楼层：整层隐藏，锚点同步隐藏；全部为空显示页面级空态
- `description` 为空：详情入口不显示，回退卡片公共信息
- 接口失败：楼层级错误态 + 重试按钮；支付取消/失败复用 `PaySheet` 现有处理
- 大字版：楼层标题与卡片文案适配大字显示模式
