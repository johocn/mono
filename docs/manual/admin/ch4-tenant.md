## 4. 多租户管理

### 4.1 功能概述

多租户管理用于管理系统中的多个租户（站点），每个租户拥有独立的渠道、课程和配置。支持：
- 创建/编辑/删除租户
- 配置站点基本信息（名称、域名、Logo等）
- 设置SEO信息
- 配置分享参数
- 开启/关闭功能开关
- 设置认证模式（本地登录/三方登录/SSO）
- 关联渠道
- 配置三方登录（微信/支付宝/抖音）
- 设置模板样式和主题色
- 设置租户行业类型（8 类预制行业，控制外卖频道准入）

### 4.2 创建租户

**操作步骤**：

1. 返回首页面板，在「🏢 多租户管理」分区点击「租户管理」
2. 点击「新建租户」按钮
3. 填写租户基本信息：

**基本信息字段说明：**

| 字段名称 | 必填 | 说明 | 示例 |
|----------|------|------|------|
| 租户名称 | * | 站点名称，显示在页面标题和分享中 | 我的教育平台 |
| 域名 | * | 站点访问域名，用于区分不同租户 | example.com |
| 租户描述 | | 站点描述信息 | 专注于职业技能培训的在线教育平台 |
| ICP备案号 | | 网站备案号，用于合规展示 | 京ICP备12345678号 |
| 客服链接 | | 客服入口链接，如企业微信 | https://work.weixin.qq.com/... |

4. 设置站点标识：

**站点标识字段说明：**

| 字段名称 | 必填 | 说明 | 建议尺寸 |
|----------|------|------|----------|
| 站点 Logo | | 站点Logo图片，显示在页面顶部 | 200x200px |
| Favicon | | 浏览器标签图标 | 32x32px |

5. 配置SEO设置：

**SEO设置字段说明：**

| 字段名称 | 必填 | 说明 | 示例 |
|----------|------|------|------|
| SEO关键词 | | 搜索引擎关键词，多个用逗号分隔 | 在线教育,职业培训,技能学习 |
| SEO描述 | | 搜索引擎展示的描述文字 | 专业的在线职业技能培训平台 |
| 腾讯地图Key | | 腾讯位置服务API Key | XXXXXXXX |

6. 配置分享设置：

**分享设置字段说明：**

| 字段名称 | 必填 | 说明 | 示例 |
|----------|------|------|------|
| 分享标题 | | 转发朋友圈时的标题 | 快来学习这门课程！ |
| 分享描述 | | 转发朋友圈时的描述 | 专业讲师授课，助你快速成长 |
| 分享封面图 | | 分享时显示的封面图片 | 推荐尺寸 500x400px |
| 分享路径 | | 分享链接指向的页面路径 | /pages/index/index |

7. 设置功能开关：

**功能开关说明：**

| 开关名称 | 默认值 | 说明 |
|----------|--------|------|
| SSO登录 | 关闭 | 启用单点登录功能 |
| 积分系统 | 开启 | 启用积分奖励系统 |
| 题库管理 | 开启 | 启用题库和考试功能 |
| 课程管理 | 开启 | 启用课程管理功能 |
| 渠道管理 | 开启 | 启用渠道管理功能 |
| 三方登录 | 开启 | 启用微信/支付宝/抖音登录 |
| OSS存储 | 关闭 | 启用阿里云OSS存储 |

8. 配置认证模式：

**认证模式说明：**

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 本地登录 | 使用账号密码或手机验证码登录 | 独立站点，无需第三方登录 |
| 三方登录 | 使用微信/支付宝/抖音登录 | 需要社交账号登录 |
| SSO单点登录 | 使用企业SSO系统登录 | 企业内部集成 |

**三方登录平台选择（认证模式为"三方登录"时显示）：**

| 平台 | 说明 |
|------|------|
| 微信公众号 | 微信网页授权登录 |
| 微信小程序 | 微信小程序登录 |
| 微信开放平台 | 微信开放平台登录 |
| 支付宝 | 支付宝登录 |
| 抖音 | 抖音登录 |

**SSO配置（认证模式为"SSO"时显示）：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| SSO登录地址 | * | SSO登录页面URL |

**注册设置：**

| 字段名称 | 默认值 | 说明 |
|----------|--------|------|
| 允许注册 | 关闭 | 是否允许用户自主注册 |
| 必填邀请码 | 关闭 | 注册时是否必须填写邀请码 |

9. 配置渠道（**必选**）：

**渠道配置说明：**

| 设置项 | 说明 |
|--------|------|
| 是否允许跨渠道 | 开启后用户可见跨渠道课程/分类，关闭后仅展示站点渠道数据 |
| 关联渠道 | 选择租户关联的渠道，只能选择你有权限的渠道 |

**操作步骤：**
- 点击「+ 添加渠道」按钮
- 在弹出的渠道选择器中选择要关联的渠道（可多选）
- 点击渠道名称左侧的复选框进行选择/取消选择
- 点击「确定」按钮确认选择

10. 点击「保存并继续」按钮保存租户信息

**注意事项：**
- 租户名称和域名为必填项，必须填写
- 渠道为必选项，必须至少选择一个渠道
- 保存后会自动生成租户的documentId，用于后续配置
- 保存后页面会刷新，进入编辑模式

11. 配置三方登录（保存租户后）：

**操作步骤：**
- 在「三方登录配置」区域点击「+ 添加配置」
- 填写配置信息：

**三方登录配置字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 配置名称 | * | 配置的显示名称 |
| 平台 | * | 选择平台：微信、支付宝、抖音 |
| 应用类型 | * | 选择应用类型：公众号、小程序、开放平台等 |
| App ID/AppID/Client Key | * | 对应平台的应用ID |
| App Secret/应用私钥/Client Secret | * | 对应平台的应用密钥 |
| 商户号 | | 支付宝平台需要填写 |
| Token | | 微信平台需要填写 |
| 启用状态 | | 是否启用该配置 |

- 点击「保存」按钮保存配置
- 配置会显示在三方登录配置列表中，可进行编辑和删除

12. 配置模板样式：

**模板样式字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 预设模板 | | 选择预设的站点模板 |
| 主题色 | | 站点主色调，影响按钮、导航栏等 |
| 辅助色 | | 辅助颜色，用于强调和次要元素 |
| 导航样式 | | 默认、渐变、自定义 |
| tabBar颜色 | | 底部导航栏背景色 |
| tabBar激活色 | | 底部导航栏激活状态颜色 |

### 4.3 编辑租户

**操作步骤**：

1. 在租户列表中点击要编辑的租户名称
2. 修改租户信息（参考创建租户的字段说明）
3. 如需修改三方登录配置：
   - 点击配置项右侧的「编辑」按钮
   - 修改配置信息
   - 点击「保存」按钮
4. 如需删除三方登录配置：
   - 点击配置项右侧的「删除」按钮
   - 在确认对话框中点击「确定」
5. 点击「保存」按钮保存修改，或点击「保存并返回」按钮保存并返回列表

### 4.4 删除租户

**操作步骤**：

1. 在租户列表中找到要删除的租户
2. 点击「删除」按钮
3. 在确认对话框中点击「确定」

> **注意**：删除租户会同时删除关联的站点配置和三方配置，此操作不可恢复，请谨慎操作。

### 4.5 常见问题与错误提示

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 提示"请填写租户名称和域名" | 租户名称或域名未填写 | 填写租户名称和域名 |
| 提示"请选择至少一个渠道" | 未选择关联渠道 | 点击「+ 添加渠道」选择渠道 |
| 提示"请先保存租户信息" | 在新建租户时未保存就尝试添加三方配置 | 先点击「保存并继续」保存租户 |
| 提示"请填写SSO登录地址" | 认证模式为SSO但未填写SSO地址 | 填写SSO登录地址 |
| 三方配置列表不显示 | 新建租户后未刷新页面 | 保存租户后等待页面自动刷新 |

### 4.6 租户行业类型

租户行业类型用于外卖频道（waimai）的店铺准入过滤：只有**餐饮行业且已配置履约**的租户才会出现在外卖店铺列表中。**仅平台管理员可修改**，租户端提交的修改会被后端拒绝。

**操作步骤**：

1. 在租户列表中点击要编辑的租户名称，进入「租户详情」
2. 在「租户基础信息」卡片找到「行业类型」下拉框，选择所属行业
3. 点击右侧「保存」按钮保存

![租户详情-行业类型编辑](../shots/2026-10-10-industry-product-type/tenant-industry-edit.png)

**行业类型说明（8 项预制）：**

| 类型 | 名称 | 典型商户 |
|------|------|----------|
| catering | 餐饮 | 餐馆、奶茶、小吃 |
| retail | 零售商超 | 便利店、超市 |
| fresh | 生鲜果蔬 | 水果店、生鲜配送 |
| service | 生活服务 | 家政、维修 |
| hotel | 酒店民宿 | 酒店、民宿 |
| beauty | 美容美发 | 美容院、理发店 |
| education | 教培 | 培训机构 |
| other | 其他 | 以上之外的行业 |

**外卖频道准入规则：**

- 外卖频道（waimai）店铺列表仅显示「行业类型 = 餐饮（catering）**且** 已配置履约配置」的租户，两个条件必须同时满足（AND 语义）
- 非餐饮行业的租户、或餐饮行业但未配置履约的租户，均不会出现在外卖店铺列表

![外卖首页-仅显示餐饮且已配履约的店铺](../shots/2026-10-10-industry-product-type/waimai-store-list.png)

**注意事项：**

- 仅平台管理员可在 web-admin 平台侧「租户管理 → 租户详情」修改行业类型；租户端越权修改会被后端拒绝
- 存量已配置履约的渠道，服务启动迁移时会自动补为「餐饮」（迁移幂等，只补空值，不覆盖已手动设置的值）

### 4.7 回归测试用例

| # | 用例 | 操作步骤 | 预期结果 |
|---|------|----------|----------|
| 1 | 外卖店铺列表准入 | 分别准备：餐饮+已配履约、非餐饮行业、餐饮但未配履约 三种租户，查看外卖首页店铺列表 | 列表仅显示「餐饮+已配履约」的租户；非餐饮、无履约的均不显示（AND 语义） |
| 2 | 平台设置行业回读 | 平台管理员在租户详情选择行业并保存，刷新后重新进入租户详情 | 行业类型下拉正确回显所设置的值 |
| 3 | 租户端改行业被拒 | 以租户身份提交行业类型修改请求 | 后端拒绝，行业类型保持不变 |
| 4 | 商品类型保存回读与默认值 | 商品编辑选择「虚拟商品」保存后重新打开；另打开一个未设置过类型的老商品 | 新保存的商品正确回显所设类型；老商品回退显示「实体商品」，保存后落为 physical（见《商品详情页手册》第 7 节） |
| 5 | 迁移幂等 | 对行业已补为「餐饮」的租户重启服务 | 行业值不变（迁移仅补 NULL，不重置非空值） |
