## 1. 认识 SSO 登录

### 1.1 什么是 SSO 登录

SSO（Single Sign-On，单点登录）就是**一次登录，到处可用**。用户登录一次后台，就能直接访问课程站点，不用重复输入账号密码。

### 1.2 为什么要用 SSO

- **用户体验好**：用户在微信里点开课程链接，自动跳转微信授权，一键登录，不用注册账号
- **统一账号体系**：后台、课程站点、其他业务共用一套账号，用户数据打通
- **支持邀请码**：新用户通过邀请码注册，自动建立推荐关系

### 1.3 整体流程（一句话看懂）

```
用户访问 v.joho.cn → 跳转到 h.joho.cn 的 SSO 登录页 → 微信授权登录 → 跳回 v.joho.cn 自动登录
```

### 1.4 涉及的两个域名

| 域名 | 角色 | 用途 |
|------|------|------|
| **h.joho.cn** | 后台管理 + SSO 中转 | Strapi 管理面板、SSO 微信授权回调、JSSDK 签名 |
| **v.joho.cn** | C 端课程站点 | 用户访问的课程页面，发起 SSO 登录 |

## 2. 准备工作

### 2.1 你需要准备的东西

| 序号 | 准备项 | 说明 | 获取方式 |
|------|--------|------|----------|
| 1 | 微信公众号（服务号） | 用于微信网页授权登录 | 在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册服务号 |
| 2 | AppID | 微信公众号的唯一标识 | 公众号后台 → 开发 → 基本配置 → 开发者ID |
| 3 | AppSecret | 微信公众号的密钥 | 公众号后台 → 开发 → 基本配置 → 重置获取 |
| 4 | 已部署好的 h.joho.cn 后台 | SSO 插件所在的后台 | 联系技术部署 |
| 5 | 已部署好的 v.joho.cn 站点 | 需要开启 SSO 登录的 C 端站点 | 联系技术部署 |

### 2.2 获取微信公众号的 AppID 和 AppSecret

1. 登录 [微信公众号后台](https://mp.weixin.qq.com)（必须是服务号，订阅号没有网页授权权限）
2. 左侧菜单点击「开发 → 基本配置」
3. 在「开发者ID」一栏可以看到 **AppID（应用ID）**
4. 点击「AppSecret」后面的「重置」，用管理员微信扫码后获取 **AppSecret（应用密钥）**
5. 将 AppID 和 AppSecret 复制保存好，**AppSecret 只会显示一次**

> ⚠️ 注意：AppSecret 非常重要，不要泄露给无关人员。如果泄露，可以在公众号后台重置。

### 2.3 配置微信公众号的 IP 白名单

在公众号后台「开发 → 基本配置」中，找到「IP白名单」，添加 h.joho.cn 所在服务器的公网 IP。否则微信接口调用会失败。

> 在后台的全局配置中打开 SSO 中心模块，这样所有租户才能看到和使用 SSO 功能。

## 4. 第二步：配置微信登录（三方绑定）

> 在 SSO 中心配置微信公众号的 AppID 和 AppSecret，让 SSO 能够调用微信的登录接口。

### 4.1 操作步骤

1. **进入 SSO 中心**：左侧菜单点击「SSO 中心 → 三方绑定」
2. **新增配置**：点击右上角「**配置微信登录**」按钮（或「+ 新增」按钮）
3. **填写配置信息**：

#### 4.1.1 基本信息区域

| 字段 | 填写内容 | 说明 |
|------|----------|------|
| **配置名称** | `h.joho.cn 微信公众号` | 给自己看的名字，方便识别 |
| **平台** | 选择「微信」 | 固定选微信，其他平台暂不支持 |
| **应用类型** | 选择「公众号」 | 网页授权用公众号，如果是小程序/APP选对应类型 |
| **AppID** | 粘贴 2.2 获取的 AppID | 公众号的唯一标识 |
| **AppSecret** | 粘贴 2.2 获取的 AppSecret | 公众号的密钥 |
| **是否启用** | 开启（绿色） | 让这个配置生效 |
| **描述** | 选填，不填也行 | 备注用途 |

#### 4.1.2 微信专属配置区域（选微信公众号时显示）

| 字段 | 填写内容 | 说明 |
|------|----------|------|
| **Token** | 选填，可以留空 | 消息校验 Token，用于接收微信消息时验证 |
| **EncodingAESKey** | 选填，可以留空 | 消息加解密密钥 |
| **OAuth Scope** | 勾选 `snsapi_userinfo` 和 `snsapi_base` | 授权范围，建议两个都勾选 |
| **授权升级** | 开启（绿色） | 静默授权获取 openid，需要用户信息时自动升级 |

**OAuth Scope 说明**：
- `snsapi_base`：静默授权，用户无感知，但只能获取 openid，不能获取昵称头像
- `snsapi_userinfo`：需要用户手动确认，可以获取昵称、头像等详细信息
- 两个都勾选后，系统会自动判断：先静默授权，需要用户信息时自动升级

#### 4.1.3 回调配置区域

这个区域是系统自动生成的，不需要手动填写。系统会自动使用回调地址：
```
/api/zhao-sso/v1/auth/wechat/callback
```

## 5. 第三步：创建 SSO 应用

> 创建一个 SSO 应用，v.joho.cn 课程站点通过这个应用接入 SSO 登录。

### 5.1 什么是 SSO 应用

每个接入 SSO 的业务方（如 v.joho.cn 课程站点）都需要一个**应用身份**，包含：
- **app_code**：应用编码，唯一标识，如 `course`
- **app_secret**：应用密钥，用于验证身份
- **redirect_uris**：回调地址，登录成功后跳转回哪里

### 5.2 操作步骤

1. **进入应用管理**：左侧菜单点击「SSO 中心 → 应用管理」
2. **新增应用**：点击右上角「**+ 新增**」按钮
3. **填写应用信息**：

#### 基本信息区域

| 字段 | 填写内容 | 说明 |
|------|----------|------|
| **应用编码 (app_code)** | `course` | 唯一编码，创建后不可修改，建议用英文小写 |
| **应用名称 (app_name)** | `课程站点` | 应用的中文名称，方便识别 |
| **应用密钥 (app_secret)** | 留空（使用默认密钥） | 可以自己填，也可以留空用系统默认 |
| **启用状态** | 开启（绿色） | 让应用生效 |
| **描述** | 选填，如 `v.joho.cn 课程站点 SSO 登录` | 备注用途 |

#### OAuth 配置区域

| 字段 | 填写内容 | 说明 |
|------|----------|------|
| **回调地址 (redirect_uris)** | 填写一行：`http://v.joho.cn/#/pages/login/callback` | 用户登录成功后跳转回 v.joho.cn 的地址 |
| **授权类型** | 勾选 `authorization_code` 和 `refresh_token` | 标准 OAuth 授权流程，两个都勾选 |

## 6. 第四步：租户开启 SSO 登录

> 在 v.joho.cn 的租户配置中，开启 SSO 认证模式，让用户访问 v.joho.cn 时走 SSO 登录。

### 6.1 操作步骤

1. **进入租户管理**：左侧菜单点击「系统管理 → 多租户管理」
2. **找到 v.joho.cn 租户**：在租户列表中找到域名为 `v.joho.cn` 的租户，点击进入编辑
3. **配置认证模式**：
   - 找到 **「认证配置」** 区域
   - 点击 **「认证模式」** 选择器
   - 选择 **「SSO 单点登录」**

### 6.2 填写 SSO 配置

选择 SSO 模式后，会出现三个配置项：

| 字段 | 填写内容 | 说明 |
|------|----------|------|
| **SSO 登录** | 开启（绿色） | 开启后用户访问此站点时走 SSO 登录 |
| **SSO 登录地址** | `https://h.joho.cn/#/pages/sso/login` | SSO 统一登录页面的地址 |
| **应用码** | `course` | 和上一步创建的应用编码一致 |

### 6.3 其他认证配置

| 字段 | 建议 | 说明 |

## 7. 验证 SSO 登录

### 7.1 在微信中测试

1. 打开手机微信，进入任意聊天窗口
2. 访问 `v.joho.cn` 的课程链接（或直接复制链接到微信中打开）

6. 登录成功后，可以看到课程内容，右上角显示用户头像和昵称

1. 在电脑浏览器中打开 `v.joho.cn`
2. 页面会跳转到 `h.john.cn` 的 SSO 登录页面
3. 非微信环境下，会显示降级登录表单（账号密码登录）
4. 输入在后台已创建的账号，点击登录
5. 登录成功后自动跳转回 `v.joho.cn`

### 7.3 验证成功标志

- 页面能正常显示课程内容
- 右上角显示用户头像和昵称
- 点击个人中心能看到用户信息
- 退出登录后重新访问，需要再次登录

## 8. 常见问题

### Q1：配置完成后，访问 v.joho.cn 没有跳转到 SSO 登录页

**可能原因和解决方法：**

1. **全局配置中 SSO 模块未开启** → 检查「系统管理 → 全局配置」中 SSO 中心开关是否打开
2. **租户配置中 SSO 未开启** → 检查 v.joho.cn 租户的「认证配置」中 SSO 登录开关是否打开
3. **SSO 登录地址填写错误** → 检查是否填写为 `https://h.joho.cn/#/pages/sso/login`
4. **应用码填写错误** → 检查是否和在「应用管理」中创建的应用编码一致

### Q2：微信授权页面提示 "redirect_uri 参数错误"

**可能原因和解决方法：**

1. **微信公众号后台未配置回调域名** → 登录微信公众号后台 → 「开发 → 接口权限 → 网页授权 → 修改」→ 添加 `h.joho.cn`
2. **SSO 应用的回调地址配置错误** → 检查「应用管理」中 redirect_uris 是否填写了正确的回调地址

### Q3：微信授权提示 "invalid appid"

**可能原因和解决方法：**

1. **AppID 填写错误** → 检查「三方绑定」中配置的 AppID 是否和公众号后台的一致
2. **AppSecret 填写错误** → 重置 AppSecret 后重新填写
3. **服务器 IP 未加入白名单** → 在公众号后台「开发 → 基本配置 → IP白名单」中添加服务器 IP

### Q4：用户授权后一直转圈，无法登录

**可能原因和解决方法：**

1. **AppSecret 错误** → 检查并重新填写 AppSecret
2. **服务器 IP 白名单问题** → 确认服务器 IP 已加入公众号白名单
3. **网络问题** → 检查服务器是否能正常访问微信 API

### Q5：登录成功后跳回 v.joho.cn 还是未登录状态

**可能原因和解决方法：**

1. **回调地址不一致** → 检查应用管理中的 redirect_uris 是否和 v.joho.cn 实际使用的回调地址一致
2. **Token 传递问题** → 检查 v.joho.cn 的回调页面是否正确接收和处理了 token 参数

### Q6：非微信环境无法登录

**可能原因和解决方法：**

1. **SSO 登录页支持降级登录** → 非微信环境会自动显示账号密码登录表单
2. **确认账号已创建** → 检查后台是否已创建了该用户的账号
3. **确认认证模式正确** → 如果是 SSO 模式，非微信环境会走降级密码登录

### Q7：如何修改已配置的微信信息

进入「SSO 中心 → 三方绑定」，点击对应配置，进入编辑页面修改即可。修改后保存立即生效，不需要重启服务。

### Q8：如何添加新的应用接入 SSO

在「SSO 中心 → 应用管理」中新增应用，填写 app_code 和回调地址，然后在对应租户的「认证配置」中填写新的应用码即可。

### 9.4 跨端「从哪页登录回哪页」结论

代码层面已确认链路成立：
- **strapi-course**：`buildSsoPageUrl(state=来源页路径)` 将 `state` 内嵌进 `return_url/c_end_url`（auth-callback 的 hash query）→ 星枢 `login-callback.redirectToTarget` 将 `token` 以 `&` 拼接其后 → `auth-callback` 可同时读到 `state + token` → reLaunch 回来源分享/详情页。
- **nshop**：`return_url = route.fullPath`（保 query）→ token 直验后 `router.replace(目标)` 精确回来源页。

> ⚠️ 真实微信 SSO 回流需已部署的 h.joho.cn + 真实微信授权登录态，自动化/子代理环境无法完整跑通，此「回来源页」需**人工 + 手机实测**确认（并核对新域名是否已加入 SSO `validateRedirectUri` 白名单）。
